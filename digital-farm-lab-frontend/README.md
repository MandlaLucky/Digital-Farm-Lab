# Digital Farm Lab (frontend only)

React + TypeScript + Vite. No backend: farms, scenarios and run results are saved in the browser (localStorage).

    npm install
    npm run dev
    npm run build

Sections: 1 Farm Setup, 2 Farm Builder, 3 Scenario Management (Browse, Create, Edit, My Scenarios, Categories), 4 Simulation Workspace, 5 Results & Learning.
